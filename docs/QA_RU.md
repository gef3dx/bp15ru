# Проверка передачи — 5 октября 2026

## Фактически выполнено

1. Исходный ZIP распакован, проверена структура семи основных страниц и двух
   форм. Программно сопоставлен текст семи исходных страниц с HTML,
   полученным из адаптированных шаблонов: текст совпадает после нормализации
   пробельных символов; тексты, программы и контакты не переписывались.
2. Контрольные суммы **178 ресурсов** совпадают с исходником: CSS,
   фотографии, логотипы, PDF. Из 179 исходных ресурсов изменён только
   `js/site.js` — блок отправки форм. Для 177 различных ссылок на ресурсы
   в шаблонах подтверждено наличие файлов.
3. Python-файлы прошли синтаксическую компиляцию (`compileall`),
   JavaScript — `node --check`, shell-скрипт — `bash -n`.
4. Клиентская логика отправки из фактически включённого `site.js` выполнена
   в Node.js с тестовыми DOM/сетевыми объектами. Проверены адрес обработчика,
   CSRF-заголовок, поля обеих форм, обработка ошибок HTTP/сети/неправильного
   ответа, сохранение введённых данных, запрет внешнего перенаправления,
   валидация телефона и блокировка повторного нажатия. **9 проверок пройдены.**
5. Выполнено сопоставление изображений исходной и перенесённой вёрстки
   в Chromium в документах, загруженных в память, без сетевой навигации:
   полные страницы «Главная» и «БЮРО» при ширине 1440 px; первые экраны
   «Главная» и «Контакты» при ширине 390 px. В соответствующих парах
   пиксели совпадают. В мобильных проверках одинаково уменьшались только
   временные картинки для ускорения предпросмотра; исходные файлы в проекте
   не уменьшались. В обоих предпросмотрах использовались одинаковые
   резервные шрифты, без загрузки Google Fonts.

Машиночитаемые результаты: `QA_checks.json`. Сравнение текста/вёрстки
использовало технический адаптер синтаксиса шаблонов для локального
предпросмотра; это **не выполнение Django-шаблонизатора**.
Тестовые серверные ответы проверяют frontend, а не сохранение в Django-базу.

## Что не подтверждено запуском в этой среде

Django здесь не установлен. Попытки установить зависимости и скачать
пакеты завершились сетевой/DNS-ошибкой. Поэтому **не запускались**:
`manage.py check`, `migrate`, Django-тесты, `collectstatic`, Gunicorn,
сборка Docker и интеграционная отправка в настоящую Django-базу.
Наличие кода этих возможностей не объявляется успешным серверным тестом.

В проект включено **27 Django-тестов**: страницы, сохранение заявок,
серверная валидация, CSRF, защита от дублей, лимит отправок, обработка
ошибок базы, не-JavaScript отправка, админка и уведомления через тестовую
почту. После установки зависимостей их следует выполнить:

```bash
python manage.py test --settings=config.test_settings
python manage.py makemigrations --check --dry-run --settings=config.test_settings
python scripts/check_assets.py
```

Для реального развёртывания дополнительно примените миграции,
выполните `collectstatic` и `check --deploy` в production-настройках.
Подключение к конкретному хостингу, изменение DNS и живого сайта Netlify,
а также отправка реальных SMTP-писем не выполнялись.
